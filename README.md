# ASP.NET Core Calculator

A beginner-friendly web calculator built with ASP.NET Core MVC and C#.

## Learning goals

- Understand the ASP.NET Core project structure
- Work with controllers, models, and Razor views
- Send HTML form data to the server
- Validate input and display errors
- Keep presentation and calculation logic separated

## Requirements

- .NET 8 SDK

## Run locally

```bash
dotnet restore
dotnet run
```

Open the URL shown in the terminal.

## Current features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero validation

## Roadmap

- Add automated tests
- Improve validation
- Add calculation history
- Persist history with Entity Framework Core
